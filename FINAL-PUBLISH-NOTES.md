# Terqivo Final Publish Build

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:4000`.

## Production / Coolify

- Build command: `npm run build`
- Start command: `npm start`
- Exposed port: `4000`
- Health path: `/api/health`

Required environment values should be copied from `.env.example` and replaced with secure production values.
