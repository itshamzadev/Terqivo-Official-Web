# Terqivo Official Web

Full-stack React, Vite, Express and MongoDB website.

## Local development

```bash
npm install
npm run dev
```

Open: `http://localhost:4000`

## Production

```bash
npm install
npm run build
npm start
```

Required environment variables are listed in `.env.example`.

## Coolify

- Build command: `npm run build`
- Start command: `npm start`
- Port exposes: `4000`
- Set `NODE_ENV=production`
- Set `PORT=4000`
- Add valid `MONGODB_URI`, `JWT_SECRET`, `CLIENT_URL`, and `VITE_SITE_URL`
