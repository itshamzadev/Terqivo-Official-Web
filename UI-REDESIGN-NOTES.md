# Terqivo Complete UI Refresh

This release applies the new professional design system across the full platform:

- Public pages and detail pages
- Navbar and responsive mobile menu
- Footer and calls to action
- Forms, inputs, buttons and badges
- Admin dashboard, tables and content surfaces
- Light and dark themes
- Responsive desktop, tablet and mobile states

The application keeps the original backend, routes, database models, content APIs and port configuration.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:4000`.
